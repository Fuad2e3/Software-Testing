## 📖 Overview
**Software Testing & Quality Assurance** is a dedicated laboratory project covering black-box, white-box, and automated testing methodologies developed at **Green University of Bangladesh**. It integrates real-world full-stack authentication modules to execute vulnerability penetration testing, brute-force rate-limiting validation, regression tests, and interview technical QA assessments.

---

## 🚀 Key Features

- 🔐 **Authentication QA & Security Testing:** Stress-testing user registration, bcrypt password hashing, and session tokens.
- 🛡️ **Brute-Force & Rate-Limiting Protection:** Verifying API middleware defenses against DDoS and automated credential-stuffing attacks.
- 📋 **Test Case & Bug Reporting:** Comprehensive test suites, boundary-value analyses, and daily test logs (`daily-log.txt`).
- 📱 **Mobile UI & Integration Testing:** End-to-end integration validation across Flutter mobile clients and local REST APIs.

## ⚙️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Fuad2e3/Software-Testing.git
cd Software-Testing
```

### 2. Run Local Authentication Test Bed
```bash
cd "Registration_Login_ with Localhost/backend"
npm install
npm start
```
